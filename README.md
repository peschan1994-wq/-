# GeoStudio

Веб-приложение на русском языке для подготовки контента для Яндекс Бизнес и 2ГИС.

## Возможности первой версии

- Три истории по реальным данным бизнеса: знакомство, услуга или акция.
- Редактирование каждого слайда, три темы оформления и собственное фото.
- Скачивание каждого слайда в PNG 1080 × 1920 или 1080 × 1080, копирование текста.
- Анализ вручную введённых данных карточки: контакты, график, услуги, фотографии и ответы на отзывы. Рекомендации и скачиваемый текстовый отчёт.
- Профиль бизнеса и черновики сохраняются в браузере. Фото нужно загружать заново.
- Произвольные текстовые задания через необязательное подключение OpenAI.

Без ИИ истории создаются по шаблонам. Анализ использует прозрачный чек-лист и не загружает карточку по ссылке. Балл не прогнозирует позиции в поиске; неизвестные числовые показатели не считаются нулевыми. Публикация историй и изменения карточек выполняются вручную в кабинетах геосервисов. Проверяйте актуальные требования площадок к изображениям.

## Запуск

Нужен Python 3.10 или новее. Сторонние зависимости и сборка не требуются.

```bash
cd /workspace/-
python3 app.py --host 127.0.0.1 --port 8000
```

Для локальной работы откройте адрес `http://127.0.0.1:8000` в браузере. В облачном onboarding этот адрес используется только для внутренних проверок, а не как публичная ссылка. Развёртывание на публичном хостинге в этот проект пока не входит.

Проверки:

```bash
python3 -m unittest discover -s tests -v
```

В репозитории также есть GitHub Actions для этих тестов. Наличие workflow не означает, что удалённый запуск уже прошёл.

## Подключение ИИ

Задания используют API OpenAI Responses. На сервере задайте переменную `GEO_AI_API_KEY` через защищённые настройки среды; не отправляйте ключ в чат и не сохраняйте его в Git. Ключ не передаётся браузеру. Необязательная переменная `GEO_AI_MODEL` выбирает доступную модель; по умолчанию `gpt-4.1-mini`.

Для облачной среды разрешите HTTPS-доступ к `api.openai.com`. При использовании прокси-секретов привяжите `GEO_AI_API_KEY` к этому домену. После подключения перезапустите сервер и обновите страницу. Доступность API, модели и квоты проверяется реальным заданием; тесты используют имитацию сервиса и не подтверждают доступ к вашему аккаунту.

После отправки задания в OpenAI уходят текст задания и профиль бизнеса. Запрос использует `store: false`. ИИ готовит тексты, но не читает геосервисы и не выполняет публикацию или изменения карточек.

## Структура

- `app.py` — сервер, генерация шаблонов, чек-лист и подключение ИИ.
- `web/` — интерфейс и экспорт PNG в браузере.
- `tests/` — проверки содержимого, валидации, HTTP и интеграции ИИ с имитацией ответа.

Приложение рассчитано на личную локальную работу: общей базы, учётных записей и ограничения расходов ИИ нет. Для публичного сервиса потребуется отдельное развёртывание с авторизацией и ограничениями запросов.
